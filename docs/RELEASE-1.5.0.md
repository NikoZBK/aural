# Aural 1.5.0

- Adds steeper and gentler low- and high-pass filters: 6 dB/octave, and Butterworth or Linkwitz-Riley slopes up to 48 dB/octave.
- Adds band solo, which plays only the part of the spectrum one filter acts on, so you can find it by ear.
- Imports more Equalizer APO and Room EQ Wizard text, including bandwidths in octaves, shelf slopes, unnumbered filters, and delays.
- Moves Match levels next to Bypass, and loudness compensation to the bottom bar, so settings that change the sound are in the main window.
- Fixes Copy EQ writing some frequencies that Equalizer APO reads 1,000 times too high.

Presets with low- or high-pass slopes other than 12 dB/octave need Aural 1.5; earlier versions play them at 12 dB/octave.
