# EQ paw icon

`Resources/AppIcon.png` is the original project icon; `Resources/AppIcon.icns` contains the macOS icon sizes. Regenerate the ICNS file with `bash scripts/make-icon.sh`.

The icon was created with OpenAI's built-in image-generation tool, then resized and converted with macOS `sips` and `iconutil`. No existing third-party logo or headphone profile was used.

## Final prompt

Design a distinctive EQ dog paw icon for Aural, a native macOS audio equalizer. Four separate rounded oval toe pads arc above one large central paw pad. Shape the central pad from five closely spaced vertical rounded green equalizer bars of varying heights, with a broad dog-paw silhouette. Solid oval toe pads, no entire dog, no claws. Dark graphite rounded-square macOS tile, subtle bevel, luminous fresh pale lime-green symbol, crisp minimal shapes and restrained dimensional highlights. Centered composition, tile filling 86 percent of the canvas, transparent outer margin and corners. One icon, no text, letters, watermark, captions, scene, or mockup.
