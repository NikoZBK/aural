# Aural 2.0.0

- App mixer: set the volume or mute of each playing app on the current output. Up to eight apps can be controlled at once; a ninth stays silent until another is reset or stops, and EQ keeps running.
- A new main window with a control rail beside the equalizer, and hover help on every control.
- A mid-2000s look in both themes: brushed metal, glossy gel buttons, segmented controls and checkboxes, inset panels, and Lucida Grande.
- Faders show level lines beside each track.
- EQ resumes when the output changes while it is still starting.
