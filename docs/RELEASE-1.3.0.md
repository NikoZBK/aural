# Aural 1.3.0

- Adds verified in-app updates using Sparkle. Updates download, install, and relaunch Aural while preserving saved settings and presets.
- Offers optional automatic update checks and downloads.
- Adds signed production packaging and a signed update feed.

Installing an update briefly stops EQ. Aural follows your existing Start EQ automatically setting when it relaunches. Users upgrading from 1.2.1 or earlier must replace the app manually once to enable future in-app updates.
